build.create cars
=================

Files:
  index.html   → Start page (describe problem + photo)
  results.html → Results page (map + mechanics + dealers + towing)

How to use:
1. Unzip this folder
2. Open the folder in VS Code (File → Open Folder)
3. Right-click index.html → Open with Live Server
   (or just double-click index.html to open in browser)

How it works:
- Type the car problem
- Optionally take/upload a photo
- Click "Find Help Near Me"
- You go to the second page with Google Maps and quick links

To publish online:
- Upload both files to any free hosting (Netlify, GitHub Pages, Vercel, etc.)
